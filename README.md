# Medical Certificate Generator

> **A Python-based automation system for employee eligibility verification and permanent medical certificate generation using Excel-based records.**

---

## ◆ Overview

The **Medical Certificate Generator** automates the verification of employee eligibility for permanent employment by analyzing service records stored in an Excel database.

The system retrieves employee information, calculates years of service, validates departmental eligibility criteria, and generates professional, print-ready certificate images.
