# MEDICAL-EMPLOYEE-CERTIFICATE-GENERATOR
# 🏥 Medical Certificate Generator

A Python-based Medical Certificate Generator built using **Jupyter Notebook**. This project aims to automate employee verification and certificate generation using an Excel database.

## Objective

The goal of this project is to build a complete certificate automation system that can:

- Read employee details from an Excel file
- Verify employee information
- Calculate years of experience
- Generate professional certificate images
- Maintain certificate records automatically

The next phase will include:
-  Employee Search System
-  Experience Calculation
-  Eligibility Verification
